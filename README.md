### 🚀 Projetos em Destaque

#### ♻️ [sisRec - Sistema de Automação para Ecopontos de Reciclagem](https://github.com/DiogoFerraresso19/SisRec-FullStack)
Aplicação Full Stack (Client-Server) desenvolvida para gerenciar operações de reciclagem com rastreabilidade, auditabilidade e controle de acesso.
* **Backend:** Java 17, Spring Boot, Spring Data JPA, PostgreSQL e Lombok.
* **Frontend:** React (Vite), React Router Dom e Axios.
* **Destaques técnicos:** Controle de Acesso Baseado em Funções (RBAC), criptografia de credenciais com BCrypt, Soft Delete para integridade histórica e travas de segurança na operação de balança.

#### 💸 [PayFlow - Carteira Digital & Motor de Transferências Pix](https://github.com/DiogoFerraresso19/payflow-fullstack)
Aplicação Full Stack que simula o núcleo de uma carteira digital moderna com abertura de conta, transferências instantâneas via Pix, extrato em tempo real e estorno de transações.
* **Backend:** Java 17, Spring Boot 4, Spring Security (JWT & BCrypt), Spring Data JPA, PostgreSQL, JUnit 5 e Mockito.
* **Frontend:** React (Vite), Axios (Interceptors) e Lucide React.
* **Destaques técnicos:** Arquitetura de Ledger imutável, chaves de idempotência (`Idempotency-Key` com UUID), bloqueio pessimista (`PESSIMISTIC_WRITE`) para evitar *race conditions* e *deadlocks*, precisão monetária com `BigDecimal` e testes unitários.
